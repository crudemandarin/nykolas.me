# Iconography handoff: Travel Log section

**From:** site agent · **To:** iconography agent · **Date:** 2026-11-11

The homepage has a new section, **Travel Log** (`#travel`, currently numbered `02`). It's an interactive globe. Pins mark places the owner has lived, and ribbons trace trips between places. Trips with Powder (CR-01) are drawn in a different colour and shape. The code is in place. One piece of art is required and one is optional.

Context files:
- Section: `src/components/sections/TravelLog.astro`
- Globe engine (canvas): `src/scripts/globe.ts`
- Data: `src/data/travel.ts`
- Existing section marks to match: `src/icons/section-*.svg`, generated by `brand/round-2-iconography/gen_glyphs.py`

---

## 1. Section mark: `section-travel` (required)

The Travel Log is the only visible section heading without a mark. The site already loads it automatically: drop the file at **`src/icons/section-travel.svg`** and `index.astro` picks it up (glob `section-*.svg` → `icons.travel`). No code change is needed.

**Deliverables** (same set as the other seven marks):
| File | Where | Spec |
|---|---|---|
| `nyko-section-travel.svg` | `brand/round-2-iconography/` | 24×24 viewBox, `currentColor` only |
| `nyko-section-travel-spot.svg` | `brand/round-2-iconography/` | 64px spot version, same as the other `-spot` files |
| `section-travel.svg` | `src/icons/` | Same art as the 24px mark with the site's a11y attrs: `aria-hidden="true" focusable="false" class="sec-ico"`, no `<title>` (see `src/icons/section-crew.svg` for the exact wrapper) |

Please add a `g_travel()` to `gen_glyphs.py` so it regenerates with the family, and add the mark to the contact sheets (`assemble.py`). If the Flight Manual explorer (`src/components/IconExplorer.astro`) lists section marks, add it there too.

**Style:** match the existing marks: 1.5 stroke, square caps, miter joins, `currentColor`, no fills except small dots. It renders at 24px next to an ember-coloured `02`.

**Concept (suggestion only, your call):** a globe (circle plus one or two meridian or latitude arcs) with a single route arc lifting off its surface, and a dot at each end. That echoes what the section draws: pins joined by ribbons that rise above the globe. It must read as clearly different from:
- `section-crew` (concentric circles + six dots),
- `section-fieldops` (terrain/contours),
- the overview rocket.

## 2. Crew-trip glyph (optional, nice to have)

Trips Powder joined are currently marked with:
- an amber **square** pin and square "comet" head on the globe (drawn in canvas, no art needed), and
- a text tag **`CR-01`** on each list row.

If you want a small mark for "with Powder" (a 16px glyph, e.g. a paw or Powder's patch silhouette reduced to a single-colour glyph), deliver it as `nyko-sym-crew-16.svg` (`currentColor`, same rules as the `nyko-sym-*` map symbols). The site agent will then put it beside the `CR-01` tag and on the "With Powder" legend key. If you skip this, nothing breaks.

## Not needed

Everything else on the globe is plain geometry from the design system, drawn in canvas: ember diamond for homes, signal circle for trips, amber square for crew trips, the bezel ticks and the north chevron. Please don't redraw them.
