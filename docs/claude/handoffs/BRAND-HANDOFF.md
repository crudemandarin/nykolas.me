You are taking ownership of the **logo and iconography of Nykolas Farhangi's personal brand (NYKO / nykolas.me)**. This document is the master reference; everything it mentions is in this export. Read this first, then `logo/DESIGN-HANDOFF.md` (design philosophy, written for the site agent) and `icons/out/README.md` (iconography file inventory). ## 1 · What this brand is

A **Soyuz launch vehicle** climbing through a **tilted orbital trajectory**, drawn as *Soviet-era aerospace poster with modern restraint*: grounded in real hardware, flat-leaning, hairline-detailed, cool desaturated field with one hot accent. Never cute, cartoony, glossy or loud. The owner is a software engineer at Stripe in Seattle; the site reads as a mission dossier. His dog Powder (white maltipoo) is the crew.

## 5 · Working with Nykolas (read this twice)

- **He iterates live and tersely.** Expect single-line directional notes ("more square", "tighten it", "like this" + an image). Ship a render fast, look at it yourself first, fix the obvious flaw before he has to name it.
- **Reference images are literal.** When he sends a picture, he wants *that*. After three freehand approximations of a dog head missed, tracing the actual bitmap was the answer. Don't be precious about drawing from scratch — trace, then clean.
- **"Cartoony" is the cardinal sin.** It has always meant: saturated candy colors, glossy gradients, bouncy shapes. The fix is palette and finish, not more detail.
- **Subtractive feedback is common.** The best-received versions came from removing things (escape tower, orbit details, the N, NYKO off the plain mark). When in doubt, simplify.
- **Always render-check before sending.** Composite sheets on both grounds; for animation, screenshot sampled frames (headless Chrome via Playwright — composition bugs like the satellite occluding the wordmark only show in motion). Send updated files with every change; he works from the file cards.
- He says "no worries" / "sry" mid-pivot — pivots are normal, not failures. Keep the generator parameterized so pivots cost one edit.

## 6 · Technical gotchas (hard-won)

- **SVG mask seams**: adjacent same-color fills in a mask antialias into visible hairlines → bridge with a matching `stroke` on the fill layer (see `onebit()` in gen3.py and `render_layers()` in common.py).
- **potracer** treats `False` as foreground — invert masks (`~mask`). Threshold the LANCZOS-upscaled RGB (not the mask) for smooth edges; Gaussian-blur + high `opttolerance`/`alphamax` to kill trace wobble. Strip `np.int64(...)` from generated literals.
- **SMIL `animateMotion`** + `stroke-dashoffset` with `pathLength` for orbit timing; co-prime durations prevent visible loops; `rotate="auto"` for the satellite.
- **Text**: all set type is outlined via fontTools (`common.text_path`) from the bundled IBM Plex Mono; patch text auto-fits to 286px max width. No `<text>` elements anywhere.
- The cloud workspace's shell can't reach arbitrary URLs (allowlist: package registries + GitHub). Fonts came from `raw.githubusercontent.com/google/fonts`.
